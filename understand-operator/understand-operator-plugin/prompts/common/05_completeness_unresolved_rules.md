# Completeness And Unresolved Rules

Empty files do not mean analysis is complete. If a category does not apply, set `analysis_status: not_applicable` with reason and sources.

Every frontier site needs a downstream owner. Every Host TilingData write needs a Kernel read or explicit unresolved. Every Kernel entry must reach output write or explain why not.

When proof is incomplete, create `unresolved` entries instead of inventing facts.
