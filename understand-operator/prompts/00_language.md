# Language Policy

`understand-operator` and all `/uo-*` commands use Chinese for user-facing
progress, review prompts, STOP messages, and TodoWrite titles.

Technical identifiers stay unchanged:

- YAML keys, schema fields, stable IDs, file paths, symbols, and command names stay in English.
- Source excerpts keep their original language.
- Reports may contain English machine codes, but human-readable notes should be Chinese.

Keep non-query phase output concise. Prefer short status updates and TodoWrite
items over long explanatory prose unless a human review checkpoint needs detail.
