# Finding / Review 输出纪律

**何时加载**：写 review finding 或裁判裁决结构时。

## 纪律

- 只读被审产物与声明证据面；不得改被审正文
- 缺少证据不得标 pass / FINDING 成立
- Finding 至少含：条件、约束、路径、影响、源码证据
- severity 使用 `high | medium | low`；reason_code 用英文稳定码（若合同要求）
- 去重：同一根因一条 finding，勿按文件刷屏

形态示例见各 Domain Skill 的 `examples.md` / `proof-certificate.md`。
