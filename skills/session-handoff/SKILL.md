# 会话交接

只引用路径，写 `session_handoff.md`。不要复制卡片或计划全文。下一窗口应能从指针继续，不必翻本会话、不必把 `{slug}_plan.md` 再贴一遍。

本步不改码、不查图、不审 diff、不构造 case。它只做索引。

## 输入 / 输出 / 停

读：当前已有正式产物路径（计划、init、worklog、审查对话位置）。写：一份 `session_handoff.md`。禁止写任何 CE yaml，禁止把源码或查询卡片全文粘进来。

完成：下一窗口能从指针继续，不必翻本会话。缺指针的段落宁可写「无」也不要编。

## 步骤

1. **列出还在进行的目标。** 一句话：现在要完成什么，卡在哪一步（计划未 apply、init 未确认、计划未批准、某条义务仍 open）。
2. **只放路径。** `{slug}_plan.md`、`tg/init.yaml`、`plan.md`、worklog、测试脚本仓根、相关 slash 进度。每条路径用反引号。不要摘抄计划 todo 列表全文。
3. **未决决策。** 从计划「未决」节或对话里抄「还没决且会影响下一窗」的项，带推荐答案。已决的不要再讲一遍故事。
4. **不要把证据正文搬过来。** 查询卡片、diff、Replay 收据全部用路径。需要细节时让下一窗自己打开。
5. **下一窗建议动作。** 一句：该 `/ce-apply`、`/tg-plan`、还是继续问人。不要在 handoff 里开始那个动作。

## 常驻判断

正式产物只有 markdown：计划与这份 handoff。禁止 `tg_plan_intent.yaml`、`change_capture.yaml`、`ce/review/`。

`/ce-plan` 与 `/ce-review` 不要在交接里混成一件事。有 diff 待审就指审查入口；有计划待做就指计划路径。

验证不在 CE：测试意图若需要，指向计划「测试内容」节或 init，让 `/tg-plan` 自己读。不要在 handoff 里展开 `P-*` 表。

LLM 禁止写 `.uo`。本步也不要宣布工作流 PASS。

## 看到这样

| 现象 | 判断 |
| --- | --- |
| 想把计划 todo 全文贴进来 | 禁止；只放路径 |
| 想粘查询卡片 / diff | 禁止；只放路径 |
| 某产物不存在 | 写「无」，不要编 |
| 审查与改码都还开着 | 分开指路径，不要混成一件事 |
| 想在本步继续干活 | 禁止；只写建议动作 |

## 完成勾选

- [ ] 目标、卡点、正式产物路径都有
- [ ] 未决只保留会影响下一窗的，带推荐答案
- [ ] 没有复制计划或卡片全文
- [ ] 下一窗建议动作只有一句

## 循环

1. 用一句话写当前目标与卡点。
2. 列出正式产物路径。没有的写「无」。
3. 只保留会影响下一窗的未决，带推荐答案。
4. 建议下一动作一句。不要开始做。

不要复制 `{slug}_plan.md` 或查询卡片全文。

## 输出形状

`session_handoff.md` 四块：目标与卡点（一句）、产物路径列表、未决（带推荐答案）、下一窗动作（一句）。缺的写「无」。

## 反模式

- 把 `{slug}_plan.md` 全文粘进来
- 粘查询卡片、diff、Replay 日志
- 编造不存在的产物路径
- 把审查和改码写成同一件事
- 在 handoff 里开始 apply / plan / 审查
- 把精度/性能场景表展开进交接文档
- 宣布工作流 PASS

下一窗靠路径打开原文。handoff 只做索引。
