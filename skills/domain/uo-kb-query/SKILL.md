# UO 知识库查询

## 核心循环

```text
理解问题
 ↓
精确解析符号
 ↓
KB / Codemap 查询
 ↓
必要时读源码校验
 ↓
回答并附证据
```

## 方法

1. 把问题收成可查询的实体或关系（定义、读写、调用、路径、完整性）。
2. 先结构化查询，再读源码切片验证。
3. 多候选同名时列出歧义，不要静默择一。
4. 答案必须带来源码或 KB 证据；不确定则标明。

**查询未命中 ≠ 源码不存在。**

## 结果

- **ANSWERED**：有证据的直接回答
- **PARTIAL**：部分回答 + 缺失项
- **UNKNOWN**：证据不足
