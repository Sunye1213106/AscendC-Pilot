# C++ / 模板语义注意点

证明涉及下列结构时按需检查，不可默认「只有一条路径」。

## 模板与实例

- 不同模板实参可能走不同函数体
- 特化 / 偏特化可能覆盖主模板结论
- 未解析到具体实例时不得对「全部实例」下结论

## 宏与条件编译

- `#if` / 宏展开可删除或改写赋值点
- 宏上下文 unknown → 完整性 `partial`，倾向 `INSUFFICIENT`

## 重载与 ADL

- 同名函数多 overload；须精确解析到被调用声明
- 不得静默选择「看起来像」的 overload

## 别名与拷贝

- 指针/引用/结构体字段拷贝可使「后续覆盖」发生在别名上
- 保存—修改—恢复模式常伪装成无覆盖

## 间接调用

- 函数指针、虚调用、回调表：目标未闭合时不得证明「无其他调用者」
