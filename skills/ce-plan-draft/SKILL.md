# 写出计划

边查边问，当场写入 `ce/plan/{slug}_plan.md`。形状见 `examples/deter-band-schedule_plan.md`。一次 apply 做一个 `- [ ]`。本步只写计划：不改码、不审 diff、不写 CE yaml。

## 输入 / 输出 / 停

读：已记录意图或增量、当前 `{slug}_plan.md`（若有）、查图卡片。

写：同一份命名 markdown。路径写在反引号里。

完成：有实现分析、分步计划、可勾选 Todo、测试内容。会改文件集的未决要么已决，要么 `UNRESOLVED` + 推荐答案。修订时 `- [x]` 仍在。中止前，已确认的结论仍须落在计划里。

## 步骤

1. **判定新写还是修订。** 没有当前计划 → 新写。有计划且本题是同一目标的增量 → 修订：`- [x]` 原样保留；已做内容与新范围冲突则新增「回滚/收窄」todo。覆盖同一路径，不另开平行文件。
2. **事实自己查，决策一轮问完。** 字段写读、Host 路径、符号是否同一、侧别（host / tiling / kernel）自己查。只问取舍：范围、不做的事、改哪一侧、测试覆盖到哪。每题带推荐答案。用户已说清的不再问。
3. **边问边写。** 已决的写进实现分析 / 分步 / todo。未决写成 `UNRESOLVED`：未决内容、推荐答案、会影响哪些步骤或文件。会改文件集的未决，不假装已决去编文件集。实现分析点名文件与符号，侧别写清。
4. **切成一次 apply 一个的 `- [ ]`。** 每项声明文件集。host 合同与 kernel 消费、算子仓与测试仓拆开。Todo 描述代码修改。
5. **测试内容写成给 `/tg-plan` 的散文。** 应观察到什么、哪类 shape / 精度还是性能、哪些旧路径保持不变。用户点名的场景 id 可以保留。按失败模式分类时读 `references/risk-classes.md`。
6. **停。** 计划落盘即停。

## 常驻判断

没有 `- [ ]` 就不是一份能 apply 的计划。修订是补丁，不是第二份计划，也不是重写历史。

计划写目标实现。PR 可以当事实来源，计划不描述 diff。

依赖写清（先改 Host 合同再改 Kernel 读者）。实现分析不写「相关代码」。

## 看到这样

| 现象 | 判断 |
| --- | --- |
| 图上能查到的字段 / 路径 / 符号 | 自己查 |
| 范围、不做的事、改哪一侧、测试覆盖 | 问人，带推荐答案 |
| 用户已经说清 | 不再问 |
| 贴了 PR URL | 事实可取；计划仍写目标实现 |
| 会改文件集的未决 | `UNRESOLVED` + 推荐答案，不编文件集 |
| 一条 todo 横跨算子仓与测试仓 | 拆开 |
| 想把刷图 / 审查 / `/tg-plan` 写成 todo | 删掉；Todo 只写改哪些文件 |
| 测试内容写成 yaml / 变量表 | 改回散文 |
| 没有当前计划却按修订做 | 新写 |
| 已勾选与新范围冲突 | 新增回滚/收窄 todo，不改 `- [x]` |
| 想在本步打补丁 | 停；写完计划后 apply |
| 没有 `- [ ]` | 还没完成 |

## 完成勾选

- [ ] 实现分析点名文件、符号、侧别、不做的范围
- [ ] 有分步计划与可勾选 Todo，一次 apply 一个，每项有文件集
- [ ] 有给 `/tg-plan` 读的测试内容
- [ ] 当前决策一轮问完；未决均为 `UNRESOLVED` + 推荐答案
- [ ] 修订时 `- [x]` 全部还在
- [ ] 路径在反引号里；没有 CE yaml、没有平行计划

## 循环

1. 判定新写 / 修订。已说清的不再问。
2. 查图核对字段、路径、侧别。事实不问人。
3. 当前决策一次问完，每题带推荐答案，同时写入计划。
4. 切 `- [ ]`，声明文件集。测试内容写成散文。
5. 不能决就 `UNRESOLVED`。停。

## 输出形状

一份 `ce/plan/{slug}_plan.md`：

```text
## 实现分析
当前行为 / 目标行为 / 侧别(host|tiling|kernel|mixed) / 文件与符号 / 依赖 / 不做的范围 / UNRESOLVED

## 分步计划
按依赖排序的实现阶段（不含查图、审查、刷图）

## Todo
- [ ] 在 `path/a.cpp`、`path/a.h` 中……（一次 apply 一项）

## 测试内容
应观察到什么；哪类 shape / 精度或性能；哪些旧路径保持不变
```

没有 `- [ ]` 不算完成。修订覆盖同一路径。

## 指针

切分或修订边界：`references/gotchas.md`。测试内容按失败模式分类：`references/risk-classes.md`。完整形状：`examples/deter-band-schedule_plan.md`。
