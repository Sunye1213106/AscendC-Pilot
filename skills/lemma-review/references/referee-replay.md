# 裁判：Replay 证书

**何时加载**：复查上一步证书、判断能否升级为排除时。

裁判**不**另开新命题，**不**重新做一遍开放式源码研究。

任务是复查证书：

1. `claim` 是否明确（P ⇒ Q）？
2. 每个标为 `CLOSED` 的义务，证据是否真的证明该义务？
3. 写入/调用枚举是否完整，还是 partial 却声称「全部」？
4. 调用路径是否成立？
5. 是否漏掉后续覆盖 / 第一行分流 / 替代入口？
6. 反例检查是否做过？声称 none 是否可信？
7. 是否与当前可达事实冲突？

## 裁决

| 结果 | 条件 |
|---|---|
| accept | 证书完整，义务关闭可信，无冲突 |
| reject | 证据不足、推理断裂、与事实冲突、或发现反例 |
| defer | 缺外部信息（源码不可读、宏上下文未知等）且无法当场关闭 |

禁止：发明缺失 citation；把未引用假设提升为已证明；修改 producer staging 正文。
