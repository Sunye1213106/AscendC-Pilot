# 算子验收标准和用例级别规范

> **重要说明**：精度标准已迁移至 `ops-precision-standard` 技能

## 1. 用例级别标准

| 级别 | 定义 | 覆盖目标 | 用例数 |
| ---- | ---- | -------- | ------ |
| L0 | 门槛用例 | 离散因子值覆盖 + InfNan覆盖 + 存在性覆盖 + 维度边界覆盖 + 格式交叉覆盖 + 场景覆盖验证 | <=200 |
| L1 | 功能/精度/性能用例 | 两两因子组合覆盖 + 边界覆盖 + 长度边界覆盖 + 数据范围覆盖 + 场景交叉覆盖 + 随机填充 | ≥500 |
| L2 | 异常用例 | 域外异常 + 约束违反 + 补充异常 | <=120 |

### 1.1 L0 覆盖策略

| 覆盖类型 | 说明 |
|---------|------|
| 离散因子值覆盖 | 每个离散因子的每个取值至少出现一次 |
| InfNan 覆盖 | 浮点 dtype 的 inf/nan 值范围至少出现一次（`support_infnan: false` 的参数除外）|
| 存在性覆盖 | 可选参数的 exist=True 和 exist=False 各至少出现一次 |
| 维度边界覆盖 | 输入 Tensor 的最小维度和最大维度各至少出现一次 |
| 格式交叉覆盖 | 多格式参数的每种格式至少出现一次 |
| 场景覆盖验证 | 若传入 `--scenarios`，验证步骤3场景枚举中的每个子场景 ID 至少被一条用例覆盖；未覆盖时自动定向求解或随机搜索补充 |

### 1.2 L1 覆盖策略

| 覆盖类型 | 说明 |
|---------|------|
| 两两因子组合（Pairwise）| 所有离散因子对的约束感知覆盖（IPO 覆盖数组 + 正向推导 + 跨类组合）|
| 边界覆盖 | 输入 Tensor 的全1 shape、Array 的空值 |
| 长度边界覆盖 | Array 参数 length=0 和 length=上界 |
| 数据范围覆盖 | 各 dtype 的默认 value_range 取值（含 inf/nan；`support_infnan: false` 时排除 inf/nan）|
| 场景交叉覆盖 | 场景 ID × 前5个关键离散因子的交叉组合 |
| 随机填充 | 覆盖目标不足 `--target-count` 时，遍历锚点笛卡尔积 × 随机 shape 生成补充 |

### 1.3 L2 异常生成策略

| 异常类型 | 具体场景 |
|---------|---------|
| 域外异常 | 不支持的 dtype（选2个无效值）、维度溢出（dimensions=9）、不支持的 format |
| 约束违反 | 输入间 dtype 不匹配（等值关系）、I/O dtype 不匹配或不可转换（可转换关系）、输出 shape 不匹配、Array 元素重复 |
| 补充异常 | 空 tensor（shape=[0]，仅对 `support_empty_tensor: false` 的参数生成）、dim 超范围（value=[999]）、必选参数缺失（exist=False）、Array 长度不匹配、格式-维度不兼容 |

每条异常用例自动附加 `_expected_error`（预期错误码）和 `_exception_type`（异常分类）。
