# scripts/dev

本地开发辅助脚本（非 CI 入口）。

| 脚本 | 用途 |
|------|------|
| `check_env.py` | 快速检查 Python / pytest / 可编辑安装 |
| `check_cann.py` | 检查 CANN / 头文件可见性 |
| `drive_uo_init.py` | 驱动本地 uo-init 跑通 |
| `run_uo_init_fast.sh` / `run_uo_init_full.sh` | UO 全量/快速 shell 驱动 |

一次性分析产物与日志见 `artifacts/scratch/`（gitignore）。
