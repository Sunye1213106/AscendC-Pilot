# uo-init paths

```text
PLUGIN_ROOT = <ascendc-agent-plugin root>
SCRIPT_DIR  = $PLUGIN_ROOT/engines/uo/uo/scripts
PROMPT_DIR  = $PLUGIN_ROOT/prompts
PROJECT_ROOT = <operator repo>
AGENT_ROOT  = $PROJECT_ROOT/.ascendc-agent
UO_ROOT     = $AGENT_ROOT/uo
```

Harness：`harness start uo-init` · `harness validate-key-gates` · `harness advance` · `harness complete`
Legacy：`harness migrate-legacy`
